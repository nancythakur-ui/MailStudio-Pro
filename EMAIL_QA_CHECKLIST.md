# Production Email QA Checklist

- [ ] Subject and preheader reviewed; no misleading claims.
- [ ] Sender name and reply-to address verified.
- [ ] Personalization has safe fallback values.
- [ ] All images have useful alt text and hosted HTTPS URLs.
- [ ] All CTA and footer links tested.
- [ ] Layout checked at mobile width and desktop width.
- [ ] Tested in Gmail, Outlook desktop/web, Apple Mail and mobile clients.
- [ ] Dark-mode behavior reviewed where relevant.
- [ ] Plain-text alternative prepared.
- [ ] Unsubscribe and preference links work.
- [ ] Consent and suppression lists applied.
- [ ] SPF, DKIM and DMARC configured for the sending domain.
- [ ] Test send approved; campaign audience and schedule confirmed.
- [ ] Final approval and deployment timestamp documented.

Note: this project's QA page is a checklist aid, not proof of inbox rendering or deliverability.
